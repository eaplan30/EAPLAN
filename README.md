# EAPLAN
Setiap karya besar berawal dari satu langkah kecil yang terencana. EA PLAN hadir sebagai ruang bagi para kreator untuk merajut mimpi, merangkai cerita, dan merawat setiap perjalanan hidup. Inisiatif ini lahir dari kisah Aritox—seorang pemimpi yang mendambakan tempat privat untuk mendokumentasikan karya dan lika-liku kehidupannya.
